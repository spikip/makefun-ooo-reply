## About this entry

The best out-of-office reply is one a real person would actually
switch on, and this one passes that test while still landing a joke.
It starts with the plain fact, out of the office until Monday, which
is exactly how every auto-reply begins. Then it tells the sender
where their email went: filed under "things I will pretend I never
saw", which is honest in a way no corporate reply ever is. The laugh
comes from recognition, because every office worker has a filing
system exactly like it, a mental drawer for emails that will never
be answered. The line is short, specific, and believable, and it
stays well inside the one hundred and sixty character cap. The
program holds the line, checks it against that cap, and writes it
to /output/entry.txt exactly as the bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one-line reply to `/output/entry.txt`.
